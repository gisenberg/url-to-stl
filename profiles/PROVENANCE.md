# Included X2D profile

The supplied `x2d-04-pla.3mf` settings were generated locally by Bambu Studio 02.07.01.62 from its installed system profiles on 2026-08-30.
No user account configuration, printer credentials, downloaded model metadata, or private project data was copied.

The source profiles were:

- `Bambu Lab X2D 0.4 nozzle`
- `0.20mm Standard @BBL X2D`
- Two instances of `Bambu PLA Matte @BBL X2D 0.4 nozzle`

Profile inheritance and included machine G-code templates were resolved before passing the settings to Bambu Studio’s CLI.
Bambu Studio exported the full project configuration and initialized the standard nozzle inventory while slicing a 10 × 10 × 2 mm test cube.
The initialized settings were retained as the generator’s baseline.
The profile uses Textured PEI Plate and the preview colors `#F5F0E5` and `#181818`.

The native machine G-code remains unmodified.
